1. 프로그램 소개

Gradius ERP란?

Gradius ERP는 우리 회사의 스태프 파견 업무 전 과정을 하나의 화면에서 처리할 수 있도록 만든 자체 개발 행정 자동화 프로그램입니다.

기존에 엑셀, 카카오톡, 전화 통화로 분산되어 있던 업무를—

📞 문의 접수 → 🧮 견적 작성 → 📝 계약 확정 → 👷 인력 배정 → 📋 출석 관리 → 💰 정산 마감

이 모든 과정을 하나의 프로그램에서 실시간으로 처리합니다.

어떤 문제를 해결하나요?

기존 문제 Gradius ERP 해결 방식
견적서를 매번 수작업으로 만들어야 함 품목 입력 → 금액 자동 계산 → 이미지 한 번에 생성
어떤 건이 계약됐는지 한눈에 안 보임 상태별 현황판으로 전체 진행상황 즉시 파악
인력 연락처·이력을 따로 관리함 STAFF DB에서 검색·필터·점수 기반 자동 추천
정산 시 지급액·미수금 계산이 복잡함 계산 자동화, 미수금 현황 실시간 표시
수익이 얼마인지 사후에야 알 수 있음 대시보드에서 예상 수익 실시간 확인
대표·팀장이 개별 보고를 기다려야 함 대표 전용 화면에서 자동 집계 현황 조회

데이터는 어디에 저장되나요?

모든 데이터는 **Google Sheets(구글 스프레드시트)**에 실시간으로 저장됩니다. 별도 서버 없이도 담당자 모두가 같은 데이터를 공유하며, 인터넷이 되는 곳이라면 어디서든 접속할 수 있습니다.

2. 업무 흐름 한눈에 보기

7단계 프로젝트 생애주기

  [1] 접수         고객이 문의를 남기면 즉시 등록
     │
  [2] 견적         품목·단가 입력 → 견적서 자동 생성 → 카카오/이메일 발송
     │
  [3] 체결         고객 확인 완료 → 계약 확정 처리
     │
  [4] 배정완료      AI가 추천한 인력 중 선택 → 직군별 배정 완료
     │
  [5] 진행중       행사 당일 출석 체크 및 근무 기록
     │
  [6] 완료         행사 종료
     │
  [7] 정산완료     인력 지급 + 고객 청구 + 세금계산서 발행

이탈 상태 (언제든 전환 가능)

상태 의미
미체결 견적 발송 후 고객이 계약을 안 한 경우
보류 일시 중단 (재개 가능)
취소 완전 취소 (최종, 복구 불가)

상태별 담당자 역할

단계 주담당 확인자
접수 영업/기획 —
견적 영업/기획 대표 (금액 확인)
체결 영업/기획 대표 (승인)
배정 운영팀 대표 (인사 컨펌)
출석 운영팀 —
정산 정산 담당 대표 (지급 컨펌)

3. 화면별 기능 설명

📊 경영 대시보드

접속 위치: 왼쪽 메뉴 → "📊 경영 대시보드"

경영 현황을 하나의 화면으로 파악합니다.

주요 정보

카드 설명
🔴 계약 대기 견적을 보냈는데 아직 계약이 안 된 건. 클릭하면 상세 목록
🟠 미체결 최종 미계약 처리된 건 수
🟡 진행 예정 앞으로 10일 안에 행사가 있는 현장 목록
🟢 이번 달 매출 정산 완료 기준 당월 누적 매출
💰 미수금 아직 입금받지 못한 금액 합계

사용 팁
- "곧 나갈 현장" 카드에서 배정이 아직 안 된 현장은 빨간색으로 강조됩니다
- 각 카드 하단 "▶ 상세 보기"를 눌러 세부 목록과 담당자 연락처를 확인할 수 있습니다
- "📋 계약 관리로 이동" 버튼으로 해당 건을 바로 처리할 수 있습니다

📞 문의 접수 및 관리

접속 위치: 왼쪽 메뉴 → "📞 문의 접수 및 관리"

고객 문의가 오면 이 화면에서 바로 등록합니다.

입력 항목

항목 설명 필수 여부
업체명 의뢰 업체 이름 ✅ 필수
행사명 행사 이름 ✅ 필수
행사 일시 날짜 + 시간 (다중 기간 지원) ✅ 필수
장소 행사 장소 권장
필요 인원 몇 명 필요한지 권장
복장 유니폼, 정장 등 선택
식사/주차 제공 여부 선택
담당자/연락처 고객측 담당 정보 권장

자동화 기능
- 등록 즉시 고유 문의번호(ID) 자동 발급
- 상태 "접수"로 자동 설정 → 대시보드에 즉시 반영

🧮 견적 통합 관리

접속 위치: 왼쪽 메뉴 → "🧮 견적 통합 관리"

견적서 작성부터 발송까지 처리합니다.

작업 순서

1. 대기열에서 프로젝트 선택
   (신규접수 / 수정중 / 체결수정 / 완료 건 탭으로 구분)

2. 품목 입력
   - 직군(경호원, 안내요원 등) 선택 → 단가 자동 입력
   - 수량, 일수 입력 → 소계 자동 계산

3. 부대비용 추가
   - 교통비, 장비비, 식비 등 별도 입력

4. 최종 금액 확인
   - 공급가액 = 품목 합계 + 부대비용 - 할인
   - 부가세 = 공급가액 × 10%
   - 합계금액 = 공급가액 + 부가세

5. 견적서 미리보기 → 저장 & 이미지로 다운로드

핵심 기능

기능 설명
복수 견적안 비교 같은 건에 대해 A안·B안 등 여러 견적 저장 및 비교
단가 자동 추천 직군 선택 시 저장된 표준 단가 자동 입력
완료 건 조회 "[완료]" 탭에서 이전 프로젝트 견적 참고 가능
견적서 이미지 생성 저장 후 이미지 파일로 다운로드 → 카카오 전송

📝 계약 관리 및 승인

접속 위치: 왼쪽 메뉴 → "📝 계약 관리 및 승인"

견적이 통과된 건을 계약으로 확정합니다.

카드형 목록으로 현재 견적 발송 완료된 건들이 표시됩니다.

계약 확정 절차

1. 카드 선택 → 상세 정보 확인
2. (선택) 사업자등록증 이미지 업로드 → 자동 텍스트 인식
3. 계약 일자 입력
4. [계약 확정] 버튼 클릭
   → 상태 "체결"로 변경
   → 정산 마스터에 청구 예정 금액 자동 등록

👷 인원 배정 관리

접속 위치: 왼쪽 메뉴 → "👷 인원 배정 관리"

체결된 현장에 적합한 인력을 배정합니다. 3단계 프로세스로 구성됩니다.

Step 1 — 후보 등록

STAFF 데이터베이스에서 인력을 검색하여 후보풀에 추가합니다.

검색 필터

필터 옵션
성별 남/여/무관
나이 범위 지정
추천도 A등급~F등급
가능 직무 경호, 안내, 서빙 등
거주지 지역 필터
일정 충돌 해당 기간 타 현장 배정 여부 자동 체크

AI 자동 추천 버튼을 누르면 가장 적합한 후보를 점수 순으로 자동 정렬합니다.

Step 2 — 직군별 배정

견적에 있는 직군(경호원 3명, 안내요원 2명 등)에 후보를 배치합니다.

  • 각 직군별 필요 인원 vs 현재 배정 인원 진행률을 막대그래프로 표시
  • 배정이 완료된 직군은 ✅ 표시
  • 초과 배정도 가능 (현장 여건에 따라)

Step 3 — 확정 및 일정 입력

  • 인력별 근무 일정 최종 확인
  • [배정 확정] 클릭 → 상태 "배정완료" 자동 전환
  • 확정된 인력 명단이 출석부, 지급내역에 자동 연동

이 화면의 하단 탭

탭 설명
📋 출석부 행사 당일 출근/퇴근 시간 기록
💰 지급 현황 인력별 지급 예정액 조회
⭐ 평가 행사 후 인력 평가 (근태·수행·외모·팀워크)

행사 당일 인력의 출퇴근을 기록합니다.

스케줄표: 행사 기간 × 배정 인력을 행렬(표) 형태로 표시

4월 15일 4월 16일 4월 17일
홍길동 09:00~18:00 09:00~18:00 —
김영희 — 10:00~20:00 10:00~20:00

자동 계산

💰 정산 및 급여 관리

접속 위치: 왼쪽 메뉴 → "💰 정산 및 급여 관리"

행사 완료 후 인력 지급과 고객 청구를 처리합니다.

TAB 1 — 전체 정산 현황

진행 중인 모든 건의 수금 현황을 한눈에 봅니다.

컬럼 설명
청구금액 고객에게 청구한 금액
받은금액 실제 입금된 금액
잔액 아직 못 받은 금액 (자동계산)
입금여부 미입금 / 부분입금 / 입금완료
지급액 인력에게 지급한 금액 합계
이익 청구금액 - 지급액 (자동계산)

TAB 2 — 건별 정산

특정 현장의 인력별 지급액을 확정합니다.

인력 목록 (배정 확정된 인원 자동 표시)
  │
  ▼ 근무일수 × 지급단가 = 지급액 (자동계산)
  │
  ▼ 추가 항목 입력 (교통비, 식비, 보너스 등)
  │
  ▼ [지급기록 일괄 저장]
     → 본사 직원은 자동으로 0원 처리 (수익 계산에서 제외)

TAB 3 — 세금계산서

법인 거래처에 세금계산서를 발행합니다.

  • 고객 정보 자동 불러오기 (사업자번호, 법인명)
  • 공급가액·부가세 자동 입력
  • 세금계산서 HTML 생성 (출력·발송용)

🔍 프로젝트 상세확인

접속 위치: 왼쪽 메뉴 → "🔍 프로젝트 상세확인"

특정 프로젝트의 처음부터 끝까지 전체 이력을 한 화면에서 봅니다.

  • 고객 정보 카드
  • 문의 내용
  • 견적 금액 내역
  • 배정된 인력 목록
  • 출석 기록
  • 지급 현황
  • 최종 이익

신규 고객 미팅 전 또는 분쟁 발생 시 전체 히스토리 확인용으로 활용합니다.

4. 대표님 전용 기능

접속 위치: 왼쪽 메뉴 최상단 → "🏢 대표님 전용"

이 화면은 대표님만의 종합 경영 보고 및 승인 센터입니다.

인사 컨펌 (지급 승인)

정산 담당자가 지급 기록을 저장하면 대표님 화면에 "인사담당자의 컨펌이 필요합니다" 항목으로 표시됩니다.

현장별 지급 목록 표시
  │
  ▼ 금액 확인
  │
  ▼ [✅ 컨펌] 클릭 → 지급 확정 처리

💡 본사 직원(최규성, 송무재, 여지은, 김영찬)은 0원으로 자동 확인 처리됩니다.

수익 보고

각 현장의 실제 수익을 분석합니다.

항목 설명
청구금액 고객에게 받기로 한 금액
지급원가 외부 인력에게 지급한 금액 합계
수익 청구금액 - 지급원가
수익률 수익 ÷ 청구금액 × 100 (%)
  • 본사 직원 투입 내역은 별도 초록색 카드로 표시 (지급원가에 미포함)
  • 출력하면 현장별 수익 보고서로 활용 가능

D-Day 지급 관리

행사 종료가 임박한 건부터 우선순위로 정렬됩니다.

D-Day 색상 의미
🔴 빨간색 7일 이내 — 즉시 처리 필요
🟠 주황색 14일 이내 — 곧 처리 필요
🟢 초록색 14일 이상 — 여유 있음

미수금·미지급 현황

  • 미수금: 고객에게 아직 못 받은 금액 (구체적 업체명 + 금액 + D-Day 표시)
  • 미지급: 인력에게 아직 지급하지 않은 금액

5. AI 비서 활용법

접속 위치: 왼쪽 메뉴 → "🤖 AI 비서"

Google Gemini AI를 활용한 자연어 경영 보조 기능입니다. 채팅 형식으로 질문하면 됩니다.

사용 예시

질문 AI가 답변하는 내용
"이번 달 매출 알려줘" 정산 완료 기준 당월 누적 금액
"미수금 현황 요약해줘" 업체별 미수금 금액과 기간
"이번 주 행사 뭐가 있어?" 행사 일정 목록
"수익률 가장 높은 현장은?" 현장별 수익률 순위
"배정이 안 된 현장 있어?" 체결 후 배정 미완료 건 목록
"지난 분기 실적 분석해줘" 매출·건수·이익 추이 요약

주의사항

  • AI는 현재 저장된 데이터를 기반으로 답변합니다
  • 복잡한 계산보다는 현황 파악·요약에 적합합니다
  • 답변이 부정확하다면 더 구체적으로 질문해 주세요

6. 자주 묻는 질문 (FAQ)

Q. 데이터를 실수로 잘못 입력했어요. 어떻게 고치나요?

견적·문의 데이터는 해당 페이지에서 다시 선택하여 수정 후 저장하면 덮어씁니다.
단, 한번 "취소" 처리된 건은 상태 복원이 불가능하니 주의하세요.

Q. 저장했는데 화면에 반영이 안 돼요.

왼쪽 사이드바 상단의 "🔄 데이터 동기화" 버튼을 클릭하면 최신 데이터로 새로고침됩니다.
일반적으로 저장 즉시 자동 반영되지만, 여러 명이 동시에 사용할 때는 수동 동기화가 필요할 수 있습니다.

Q. 같은 이름의 인력이 두 명 있어요. 구별이 안 돼요.

STAFF 데이터베이스에서 이름 뒤에 구분자를 추가하세요.
예: 홍길동(여), 홍길동(강남) 처럼 괄호로 구분하면 배정 시 혼동을 방지할 수 있습니다.

Q. 견적서를 고객에게 어떻게 보내나요?

견적 통합 관리 → 저장 후 "견적서 이미지 다운로드" → 카카오톡/이메일로 수동 전송합니다.
발송 후 "발송 완료" 버튼을 눌러두면 이후 발송 일시와 방법이 기록됩니다.

Q. 세금계산서를 발행해야 해요.

정산 및 급여 관리 → TAB 3 세금계산서 → 해당 건 선택 → 법인 정보 입력 → 생성.
고객사 정보(사업자번호, 이메일)가 미리 등록되어 있으면 자동으로 불러옵니다.

Q. 보류 상태인 건은 어떻게 재활성화하나요?

해당 프로젝트 상세 화면에서 상태 드롭다운 → "접수" 또는 이전 단계로 변경 가능합니다.

Q. 인력의 추천도(등급)는 어떻게 결정되나요?

행사 후 평가 탭에서 입력한 점수(근태, 수행, 외모, 팀워크)가 자동 집계되어 A~F 등급으로 표시됩니다.
평가 누적이 많을수록 더 정확한 등급이 산출됩니다.

Q. 동시에 여러 명이 접속해도 괜찮나요?

기본적으로 가능합니다. 단, 같은 건을 동시에 두 명이 수정하면 마지막 저장 내용으로 덮어씌워집니다.
중요한 수정 작업은 한 명씩 순서를 정해 진행하는 것을 권장합니다.

7. 데이터 관리 원칙

데이터가 저장되는 곳

모든 데이터는 Google Sheets(구글 스프레드시트) 1개 파일에 시트(탭)별로 저장됩니다.

시트명 저장되는 정보
문의작성 고객 문의 전체 목록
견적상세 견적 금액 정보
견적품목 품목별 세부 내역
배정기록 인력 배정 이력
출석부 날짜별 출근 기록
지급내역 인력별 급여 지급 내역
계약건은청구금액적기 정산 마스터 (청구·수금 현황)
STAFF 인력 데이터베이스
고객정보 거래처 정보

데이터 보안 수칙

✅ 해야 할 것
  - 퇴근 시 반드시 브라우저 탭 닫기 (자동 로그아웃 없음)
  - 인력 개인정보(연락처, 주소)는 업무 목적으로만 활용
  - 이상한 오류 발생 시 캡처 후 개발자에게 보고

❌ 하면 안 되는 것
  - Google Sheets를 직접 열어서 수정하기 (프로그램의 데이터 구조가 깨질 수 있음)
  - 시트의 헤더(첫 번째 행) 이름 변경하기
  - 데이터 행을 직접 삭제하기

정기 백업

현재 데이터는 Google Sheets에만 저장됩니다. 중요 데이터는 매월 1회 Google Sheets를 Excel 파일로 수동 다운로드하여 보관하는 것을 권장합니다.

Sheets → 파일 → 다운로드 → Microsoft Excel(.xlsx)

8. 비상 상황 대처법

상황 1: 화면이 멈추거나 오류 메시지가 나타남

1단계: 브라우저 새로고침 (F5 또는 Ctrl+R)
2단계: 그래도 안 되면 브라우저 캐시 삭제 후 재접속
3단계: 왼쪽 사이드바 "🔄 데이터 동기화" 클릭
4단계: 위 모두 실패 시 → 개발자에게 오류 메시지 캡처 후 전달

상황 2: 데이터가 갑자기 사라진 것처럼 보임

1단계: "🔄 데이터 동기화" 클릭 (캐시 문제일 가능성 높음)
2단계: 검색 필터가 걸려있지 않은지 확인
3단계: Google Sheets 직접 확인 (데이터가 거기 있으면 동기화 문제)
4단계: Google Sheets에도 없으면 → 즉시 개발자 연락

상황 3: 잘못된 상태로 변경됐어요 (예: 실수로 "취소" 처리)

⚠️ "취소" 상태는 되돌릴 수 없습니다.
→ 개발자에게 문의하여 데이터 직접 수정 요청
→ 문의ID, 업체명, 행사명을 메모해두면 복구가 빠릅니다.

상황 4: 프로그램 자체가 접속이 안 됨

1단계: 인터넷 연결 확인
2단계: 다른 브라우저로 접속 시도 (Chrome 권장)
3단계: 서버 재시작이 필요할 수 있음 → 개발자 연락

긴급 연락처

프로그램 관련 문의 및 장애 보고는 개발 담당자에게 연락하세요.

💡 문의 시 반드시 포함할 정보: 오류 메시지 캡처 / 어느 화면에서 / 어떤 작업 중 / 언제 발생
